Privacy Policy

Last updated: November 10, 2026

AgenticView is a personal, self-hosted application run by its owner on their own computer. This policy explains how it handles Google user data obtained through the Gmail API.

Data accessed

When the owner connects a Google account, AgenticView may read email threads, messages and labels, and may create drafts, only to show threads inside the app and help draft replies.

How data is used

  • Data is used only to provide the features the owner requests inside AgenticView.
  • No email is sent without the owner's explicit confirmation.
  • Data is not sold, shared with third parties for advertising, or used to build user profiles.

Storage

Data and OAuth tokens are stored only on the owner's own computer. The owner can delete them at any time by disconnecting Gmail in AgenticView.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

AgenticView's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised through the repository hosting this page.
